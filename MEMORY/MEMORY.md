# 零钱簿 · 阿砚项目记忆

本目录保存仓库内可复核的长期上下文。它不是聊天摘要，也不保存真实账目、密钥、配对码或生产环境信息。

## 文件分工

| 文件 | 用途 |
| :--- | :--- |
| [`事实.md`](./事实.md) | 当前可验证的代码、版本、测试、构建和仓库状态 |
| [`决策点.md`](./决策点.md) | 已确认的产品、数据、安全与工程决策 |
| [`待办.md`](./待办.md) | 按优先级维护尚未完成的工作 |

## 当前一句话

零钱簿是中文、人民币、本机优先的个人财务网站；阿砚是完全在页面内工作的账灵。跨设备同步是用户主动启用的可选能力，不能成为本机记账的前置条件。

## 维护规则

1. 当前事实只从仓库、命令输出和当次验收中更新。
2. 历史部署或旧工作目录只能标为历史证据，不能写成当前状态。
3. 重大产品、架构、隐私或数据决策进入 `决策点.md`。
4. 未完成事项进入 `待办.md`，完成后保留日期与验证证据。
5. 不在本目录记录真实金额明细、用户标识、密钥或可复用配对材料。
