# 零钱簿 · 阿砚变更记录

## 2026-08-10 · 1.0.2 P1 质量完善

### 类型

数据一致性测试、无障碍修复、加载性能优化和界面回归扩充。

### 变更内容

- 增加流水编辑删除、预算新增编辑删除、自定义分类依赖、清空数据、CSV 错误恢复及对应同步事件的组件集成测试。
- 为删除、预算、导入和清空失败补充明确中文反馈，避免可恢复错误静默失败。
- 完善弹窗自动聚焦、Tab 焦点圈定、Escape 关闭和焦点归还；补齐金额、备注、配对、清空与 CSV 控件标签。
- 为预算进度、当前导航和分类选中状态补充语义属性，增加更高对比和 Windows forced colors 样式。
- 为六个月趋势、十二个月收支和支出分类图提供辅助技术可读的数值表。
- 将首页趋势改为轻量 SVG，报表图表改为动态加载，并阻止首页预载图表公共块。
- 将实际加载的两张水墨素材转换为 WebP；原 PNG 保留为源素材。

### 验证结果

- `npm.cmd test`：8 个测试文件、41 项测试通过。
- `npm.cmd run build`：TypeScript 检查和 Vite 生产构建通过。
- 实际加载图片由原 PNG 合计约 3.74 MB 降至 WebP 合计约 223 kB，减少约 94%。
- 图表块为 421.65 kB、gzip 114.85 kB；首页无图表 `modulepreload`，进入报表后才加载。
- 1440×900 与 375×812 隔离浏览器验收无横向溢出，弹窗未越界，控制台 0 warning、0 error。
- 375px 弹窗最终焦点稳定在金额输入框；测试流水已从隔离来源删除。

### 边界

## 2026-08-10 · 1.0.1 P0 发布候选可信度补齐

### 类型

同步与数据可靠性修复、发布前验证和文档治理。

### 变更内容

- 将 CSV 事务写入下沉到数据层，支持隔离测试首次建库、v1→v2 升级、导入成功和中途失败回滚。
- 抽出同步事件应用与离线队列逻辑，补齐错误密钥、损坏密文、唯一 IV、重复事件、离线持久化和流水冲突收敛测试。
- 确认同步入队失败时，本机已经保存的流水不会丢失。
- 使用本机进程内 PostgreSQL 和每月 0 美元的独立 Supabase 项目执行当前 schema，覆盖 anon、非成员、成员、跨房间以及禁止篡改/删除事件的 RLS 边界。
- 显式撤销 Supabase 默认授予 `authenticated` 的多余表权限，把成员检查函数移入未暴露的 `private` schema，并显式禁止 `anon` 调用同步 RPC。
- 修复缺少 favicon 造成的浏览器控制台 404，并缩小阿砚的可点击与显示区域，避免遮挡预算保存按钮。
- 生成 Cloudflare Pages 直传 ZIP、逐文件 SHA-256 清单和 1.0.1 发布候选记录。

### 验证结果

- `npm.cmd test`：8 个测试文件、35 项测试通过。
- `npm.cmd run build`：TypeScript 检查和 Vite 生产构建通过。
- 最终 `dist` 在 1440×900 与 375×812 全新浏览器会话通过关键路径、溢出和弹窗边界验收；控制台 0 warning、0 error。
- ZIP 根目录、`assets/...` 正斜杠条目、字节大小和 SHA-256 已复核。

### 边界

- 未创建每小时计费的 Supabase 分支；免费测试项目的数据已清零并暂停。
- 未创建 Git 提交、标签，未推送、未部署，也未接触真实账目或旧 Supabase 项目。
