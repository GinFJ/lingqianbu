# 零钱簿 · 阿砚发布检查清单

> 只有用户当次明确授权发布或部署时才执行本清单。勾选必须有证据，不能沿用旧工作目录的结论。

## 一、范围与版本

- [ ] 发布范围已确认，没有夹带无关改动。
- [ ] `package.json` 与 `package-lock.json` 版本一致。
- [ ] README 版本徽章、事实库和变更记录已同步。
- [ ] 当前 Git 分支、提交和工作树状态已记录。
- [ ] 未提交的用户改动已识别并保留。

## 二、隐私与安全

- [ ] 仓库与产物不含 `.env.local`、服务端密钥、真实配对材料或生产二维码。
- [ ] `.env.example` 只含无效占位值。
- [ ] 未包含真实账目、可复用用户标识或敏感日志。
- [ ] 同步变更已覆盖错误密钥、损坏密文、唯一 IV、离线队列、重复事件和冲突。
- [ ] RLS 已在隔离项目验证未授权和授权边界。
- [ ] 同步失败不会阻塞本机记账或删除已确认数据。

## 三、数据正确性

- [ ] 金额在持久化层仍为整数分。
- [ ] 日期保持本地日历语义，CSV 使用 `YYYY-MM-DD`。
- [ ] CSV 表头、BOM、非法行提示和重复识别已验证。
- [ ] 编辑、删除和清空数据后的汇总与同步事件一致。
- [ ] IndexedDB 版本变化包含升级路径和旧数据回归测试。

## 四、测试与界面

- [ ] `npm.cmd test` 实际通过，结果已记录。
- [ ] `npm.cmd run build` 实际通过，结果已记录。
- [ ] 桌面端主要导航、快速记账、编辑删除、预算、报表、CSV 和同步入口已检查。
- [ ] 375px 视口无横向滚动、文字截断、按钮遮挡或弹窗越界。
- [ ] 控制台无未处理错误。
- [ ] 键盘焦点、表单标签、对比度和错误状态已检查。

## 五、产物

- [ ] ZIP 根目录包含 `index.html`。
- [ ] 静态资源位于 `assets/...`，ZIP 条目使用正斜杠。
- [ ] 产物名称、字节大小和 SHA-256 已记录。
- [ ] Node、npm、操作系统和构建命令已记录。
- [ ] 本地预览使用实际发布产物验收。

## 六、部署后

- [ ] 正式 URL、部署时间和平台状态已记录。
- [ ] 页面 DOM、脚本、样式和水墨素材加载正常。
- [ ] 桌面和 375px 再次检查。
- [ ] 若授权同步验收，只使用可识别、可删除的测试流水。
- [ ] 测试流水在所有设备清理完成。
- [ ] 生产配对链接、二维码和临时截图已安全处理。
- [ ] 项目志、事实库和变更记录更新为最终状态。
